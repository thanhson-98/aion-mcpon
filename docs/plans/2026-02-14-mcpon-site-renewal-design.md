# MCPon Service Site Renewal Design

## Overview

AutoDate (autodate.jp) のクローンサイトをベースに、AION株式会社の新サービス「MCPon」のサービス紹介サイトにリニューアルする。

### Goals
- **Primary**: MCPonの価値・機能を正確に伝えるサービス紹介サイト
- **Secondary**: リード獲得（無料相談・資料ダウンロード）

### Constraints
- 既存サイト構造を最大限活用（段階的置換アプローチ）
- 技術スタック: jQuery + Splide + AOS を継続
- フォームはHTMLのみ（ダミー）、バックエンド接続なし
- アイコンは Font Awesome を使用
- 画像アセットは必要に応じて Codex MCP で生成

## Brand Guidelines

| Role | Color | HEX |
|------|-------|-----|
| Primary Pink | 鮮やかなピンク | `#D14A76` |
| Primary Purple | 深みのあるパープル | `#422C81` |

| Background | ホワイト | `#FFFFFF` |

| Gradient | ピンク→パープル→ブルー | `#D14A76 → #422C81 → #5B8CC3` |

### Typography
- Primary: "Zen Kaku Gothic New" (既存継続)
- Fallback: 游ゴシック, Yu Gothic, メイリオ, Meiryo, sans-serif

### Logo Assets
- `MCPon_ロゴ.png`: MCPアイコン + 電源マーク（カラーグラデーション）

- 白背景をベースに、AIONロゴ色の極めて淡いグラデーションを環境光的に配置

## Technical Implementation

### Files to Modify
- `index.html`: 全セクションの内容差し替え + 新規セクション追加
- `assets/css/style.css`: カラー変更 + 新規セクションCSS追加

### Files to Add
- Font Awesome CDN リンク（head内）
- 新規画像アセット（必要に応じてCodex生成）

### Key CSS Changes
1. AutoDateのブランドカラー（黄色系）→ AIONカラー（ピンク〜ブルー）に全置換
2. CTAボタンのグラデーション定義
3. 新規セクション用CSS（業務ステップ、特徴カード等）
4. 背景の淡いグラデーション環境光

### Animation Requirements
- スクロールアニメーション: AOS (既存)
- スライダー: Splide (既存)
- ホバーエフェクト: CSS transition (既存 + 拡張)
- カード出現: 左右からのフェードイン (AOS data-aos="fade-left/right")
- CTAボタン: ホバーで浮き上がり + グロー効果
